# 🩺 MediGest

MediGest est une application web dynamique de gestion et de planification de rendez-vous médicaux, développée dans le cadre du projet de certification **Développeur Web et Web Mobile (DWWM)**.

---

## 🚀 Fonctionnalités principales

- **Authentification sécurisée** : Inscription et connexion des utilisateurs avec hachage des mots de passe (`password_hash`) et gestion des sessions PHP.
- **Tableau de bord interactif** : Suivi centralisé des rendez-vous enregistrés.
- **Gestion des rendez-vous (CRUD)** : Ajout de nouveaux rendez-vous avec le nom/prénom du patient, la date, l'heure et le motif, et possibilité de supprimer un rendez-vous.
- **Expérience utilisateur (UI/UX)** : Formulaires ergonomiques avec option de visibilité du mot de passe (affichage/masquage dynamique via JavaScript).

---

## 🛠️ Stack technique

- **Front-end** : HTML5, CSS3 (Design responsive), JavaScript.
- **Back-end** : PHP 8 (natif, architecture orientée sécurité).
- **Base de données** : MySQL (manipulation sécurisée via PDO et requêtes préparées).
- **Environnement de test** : XAMPP / Apache.
